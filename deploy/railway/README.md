# Railway service files

Use these files from two Railway services connected to the same repository:

- `network-api`: config path `/deploy/railway/api.railway.json`
- `network-portal`: config path `/deploy/railway/portal.railway.json`

Copy the corresponding `.env.example` file into each service's Railway Variables Raw Editor, then replace placeholders and generate public domains as described in `docs/RAILWAY_DOCKER_DEPLOYMENT.md`.
