# Social Journal and relationship insights

This branch integrates the first server-backed Social Journal and Companion relationship aggregate.

## Scope

- one-call Desktop Social overview endpoint
- host Companion snapshot on Visit sessions
- Social Journal topic, transcript, and Shared Moment data in My Network Portal
- user-visible Companion relationship list and detail pages
- relationship aggregate updated exactly once per Shared Moment
- Network data export includes relationship aggregates

Private local Memory, Notebook content, credentials, and Private Reflection remain outside Network storage.
